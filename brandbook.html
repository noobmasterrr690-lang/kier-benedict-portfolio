04 // SPATIAL & INTERACTION RULES

Layout, 3D Depth & Responsive Grid

Core UI/UX engineering principles governing both desktop 4K and mobile portrait viewports.

RULE 01 // DEPTH

2-Layer Airbrush Hero Reveal

The hero stage layers tactile 3D sculptures and the primary PORTFOLIO display behind Kier’s triple-pose cutout, revealing the front typography layer only under a soft-radius cursor airbrush mask.

RULE 02 // CURATION

Vox Cards & 3D Folders

All 32+ works are organized into bespoke 3D Vox discipline stages (01–05) and 4 interactive hinged 3D folders so visitors can inspect works without endless vertical scrolling.

RULE 03 // MOBILE PRECISION

Proportional 1×3 & 2×2 Grids

Mobile viewports lock horizontal overflow (overflow-x: clip) and proportionally scale the PC layout into readable 2×2 content cards, 1×3 signature plates, and a miniature fanned arc.
